# Export and share

Use the Command Palette or the slide explorer actions to export a presentation.

## PDF

Run **Revealjs: Export in PDF**. Configure fragment handling and page sizing with `revealjs.pdfSeparateFragments`, `revealjs.pdfMaxPagesPerSlide`, and `revealjs.pdfPageHeightOffset`.

## HTML

Run **Revealjs: Export in HTML** for a single presentation file, or **Revealjs: Export Markdown Folder to HTML** to export a folder of Markdown files.

Set `revealjs.selfContained` to `true` when the exported HTML should inline local assets for portable sharing.
