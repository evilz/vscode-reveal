# Features

This section documents features verified against the VS Code Reveal extension. Each page includes a copyable source example and a rendered result where the behavior is visual.

## Start with examples

Open the [live example gallery](/features/examples) to see the main rendering features together.

## Supported feature areas

- [Themes and transitions](/features/themes)
- [Fragments and animations](/features/fragments)
- [Diagrams, math, and code](/features/content)
- [Navigation and presenter tools](/features/navigation)

The extension also passes through capabilities from Reveal.js. Those are listed separately and should be checked against the [official Reveal.js documentation](https://revealjs.com/).
